# CAT 2026 Mission

A deployable static clone of the Emergent preview app at `https://exam-streak-hub-1.preview.emergentagent.com/`.

## What is included

- Today mission checklist with date navigation
- 172-day CAT 2026 plan from June 7, 2026 to November 25, 2026
- Six-book reading runway
- Vocabulary bank with R1/R2/R3 revision tracking
- Article log
- Streak ladder and level calculations
- Consistency heatmap and weekly completion bars
- Browser `localStorage` persistence, so no backend is required

## Deploy

Upload this folder to any static host, or run locally with:

```bash
npx serve .
```

You can also deploy directly to Netlify, Vercel, GitHub Pages, Cloudflare Pages, or any host that serves static HTML/CSS/JS.
